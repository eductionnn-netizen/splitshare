# Результаты локальной проверки — 22.10.2026

Среда: Python 3.9.6, текущий Mac. Внешние Python-зависимости не устанавливались.

| Проверка | Результат |
|---|---|
| `python3 -m unittest discover -s tests -v` | 15 тестов, OK |
| `python3 scripts/build.py` | Создан `dist/splitshare.pyz` |
| `python3 scripts/smoke.py` | Собранный архив выполнен, `SMOKE PASSED` |

Проверены: обычный расчёт, остаточные копейки, плательщик вне получателей,
пустые расходы, одна персона, неверные суммы, неизвестные и повторные участники,
неверная структура данных, отсутствие изменения входных данных, CLI и плохой JSON.
Дополнительно один тест проверяет сохранение сумм и полное погашение балансов
для десяти воспроизводимых наборов групп по 30 расходов.

Демонстрация: Аня +170000 коп., Борис −40000 коп., Вика −130000 коп.
Предложены переводы Вика → Аня 130000 коп. и Борис → Аня 40000 коп.

Не проверены: GitHub Actions, регистрация self-hosted runner, опубликованная wiki,
отрисовка Mermaid на сервере, приглашения и внешняя доска. Будущий веб-продукт
из квартального плана ещё не реализован.
