# SplitShare — дружба отдельно, долги отдельно 💸

Учебный проект приложения для разделения общих расходов между друзьями.
Один оплатил пиццу, второй — такси, третий обещал «потом перевести»: SplitShare
показывает, кто сколько потратил и кому сколько нужно вернуть.

## Практики

| Блок | Подготовленные материалы | Что ещё требует внешнего сервиса |
|---|---|---|
| 1. Git и wiki | [6 страниц wiki](wiki/Home.md), боковое меню | Создать репозиторий, пригласить участников, опубликовать wiki |
| 2. Доска | [10 задач с критериями приёмки](planning/Backlog.md), процесс и правила переходов | Создать Issues и доску; провести реальные переходы |
| 3. Квартал | [6 спринтов и диаграмма Ганта](wiki/Quarter-plan.md), 3 команды, зависимости | Проверить отображение диаграмм после публикации |
| 4. CI/CD | Прототип, тесты, сборка zipapp, workflow для self-hosted runner | Зарегистрировать runner и получить успешный запуск Actions |

Это подготовленный локальный комплект, а не свидетельство выполнения действий на Git-сервере.
Команды и квартальный план — учебная модель; реальные участники пока не назначены.

## Запуск прототипа

Нужен Python 3.9 или новее. Внешних Python-зависимостей нет.

```bash
python3 app/splitshare.py examples/weekend.json
python3 -m unittest discover -s tests -v
python3 scripts/build.py
python3 dist/splitshare.pyz examples/weekend.json
```

Прототип — консольный расчёт расходов одной группы в рублях. Он проверяет входные
данные, делит расходы поровну с точностью до копейки и предлагает взаиморасчёты.
Веб-интерфейс, аккаунты, постоянное хранилище, уведомления и реальные платежи
в эту версию не входят: они описаны как дальнейшая работа в квартальном плане.

## Пример

Аня оплатила ужин на 3000 ₽ за троих, Борис — такси на 900 ₽ за тех же троих.
Общие расходы — 3900 ₽, доля каждого — 1300 ₽.

| Участник | Оплатил | Его доля | Баланс |
|---|---:|---:|---:|
| Аня | 3000 ₽ | 1300 ₽ | +1700 ₽ |
| Борис | 900 ₽ | 1300 ₽ | −400 ₽ |
| Вика | 0 ₽ | 1300 ₽ | −1300 ₽ |

Результат: Вика → Аня 1300 ₽, Борис → Аня 400 ₽.
