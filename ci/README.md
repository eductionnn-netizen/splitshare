# CI в отдельном приватном репозитории

Публичный `splitshare` хранит исходники, задачи и документацию. В нём нет активного workflow и зарегистрированного self-hosted runner.

Приватный `eductionnn-netizen/splitshare-ci` содержит проверенную копию файлов приложения, тестов и сборочных скриптов. `SOURCE.json` фиксирует исходный коммит и SHA256 каждого файла. Workflow запускается вручную на `main` и разрешает выполнение только в `eductionnn-netizen/splitshare-ci`. Метка runner — `splitshare-private`.

## Обновление копии

1. Выбрать конкретный коммит основного репозитория и проверить изменения приложения, тестов, скриптов и зависимостей.
2. Скопировать только `app/splitshare.py`, `tests/test_splitshare.py`, `scripts/build.py`, `scripts/smoke.py`, `examples/weekend.json` и `.gitignore` в приватный репозиторий.
3. Обновить исходный SHA и контрольные суммы в `SOURCE.json`. Проверить diff приватного коммита.
4. Запустить runner на время выполнения сборки и вручную запустить workflow на `main` приватного репозитория.
5. Проверить результаты тестов, сборки и пробного запуска, скачать артефакт `splitshare-app`. После работы остановить runner.

Публичные PR не синхронизируются и не запускаются автоматически. Доступ к записи в CI-репозиторий даётся только тем, кому доверено выполнение кода на компьютере runner. Приватность репозитория не заменяет проверку запускаемого кода. Постоянный автозапуск runner не установлен.
